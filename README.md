# YouTube Ext

[English](README.EN.md) | Русский

Набор улучшений для YouTube в одном юзерскрипте: скорость воспроизведения отдельно для каждого канала, управление автозапуском видео и плавающее окно плеера при прокрутке комментариев.

## Возможности

### Скорость для каждого канала
- Запоминает выбранную вами скорость отдельно для каждого канала и автоматически применяет её ко всем роликам этого канала.
- Синхронизирует внутреннее состояние плеера YouTube, поэтому меню скорости («Playback speed») сразу показывает правильное значение после перезагрузки страницы.
- Переживает рекламу и служебные сбросы YouTube: если после рекламы скорость слетела — тихо вернёт сохранённую.
- Отличает ручную смену скорости (клики по пресетам, ползунок, горячие клавиши) от служебных — ручной выбор сохраняется для канала.
- Отличие ручной смены скорости (пресеты, ползунок, горячие клавиши) запоминается для канала.

### Автозапуск видео
- Тумблер «Автоматически запускать видео»: если выключен — открытое видео сразу ставится на паузу и не играет, пока вы сами не нажмёте Play.
- YouTube может повторно запускать ролик после его дозагрузки — скрипт глушит каждый автозапуск, но не вмешивается после ручного запуска.
- Рекламу не трогает.

### Плавающее окно плеера
- Когда при прокрутке комментариев плеер полностью уходит за верх экрана, видео уезжает в компактное окно (426×240) в правом нижнем углу.
- Работает и в обычном режиме, и в «театральном»; в полноэкранном режиме отключается.
- Скрывает размытый «кинематический» фон, который YouTube оставляет на месте плеера.
- Мигание исключено: положение плеера запоминается при входе в плавающий режим, выход — по факту обратной прокрутки.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Vivaldi и другие Chromium-браузеры; также работает в Violentmonkey/Greasemonkey).
2. Откройте ссылку на скрипт и подтвердите установку:
   [youtube-ext.user.js](https://raw.githubusercontent.com/r35p3ct/Youtube-ext/main/youtube-ext.user.js)
3. Обновления приходят автоматически: Tampermonkey проверяет metadata по `@updateURL`.

Либо вручную: создайте новый скрипт в Tampermonkey и вставьте содержимое `youtube-ext.user.js`.

## Настройки

Кнопка-шестерёнка **слева от штатной шестерёнки YouTube** в панели управления плеером открывает окно настроек:

| Группа | Тумблер | Действие |
|---|---|---|
| Воспроизведение | Автоматически запускать видео | выкл. — открытое видео стоит на паузе до ручного запуска |
| Плеер | Плавающее окно при прокрутке | мини-плеер в правом нижнем углу при прокрутке |
| Скорость | Запоминать скорость для каждого канала | вкл. — применять и запоминать скорость по каналам |

Настройки хранятся через `GM_setValue`; сохранённые скорости каналов — в отдельном ключе (совместим со старым скриптом «YouTube Channel Speed»).

## Совместимость

- Настольный YouTube (`www.youtube.com`), Chromium-браузеры (Chrome, Edge, Vivaldi, Opera).
- Протестировано с новым интерфейсом плеера YouTube 2025+ (панель скорости с пресетами и ползунком, Trusted Types CSP).
